# Task 185 — Per-task proof paths (`.proof/task-<id>/proof.md`)

## Problem (root cause)

The evidence protocol wrote every task's proof to the SAME shared path
`.proof/proof.md`. The data is inherently per-task, but the path was not —
so when two task branches merged to one spec branch, the second task's
`.proof/proof.md` conflicted with the first (seen live: one task's merge
deleted another's proof). The fix is at the path-convention layer: namespace
by task id.

## Changes

### `odin/src/odin/promote_check.py`
- Replaced `DEFAULT_PROOF_ARTIFACT = ".proof/proof.md"` with:
  - `LEGACY_PROOF_ARTIFACT = ".proof/proof.md"` — kept for backward-compat fallback.
  - `default_proof_artifact(task_id) -> str` — returns `.proof/task-<id>/proof.md`.
- Rewrote the acceptance-artifacts gate: checks the per-task path first, falls
  back to the legacy shared path for tasks created before the switch. Reports
  whichever path was actually found; when neither exists, names the per-task
