# Memory

**Why.** The kit has run hundreds of tasks and recorded every trace, cost,
failure, and fix. All of it sits unread. A kit that remembers turns every
past task into a head start for the next one. It's the difference between a
tool and a colleague, and it's the bucket where the kit starts to feel
alive.

**Ideas.**
- Task twins. A new task arrives, the kit searches every past task for the
  closest matches, and shows their cost, time, agent, redo count, and
  outcome. The twin's notes and proof come along as starting context.
- A quote before dispatch. From the twins: "estimate, 15 minutes, $0.40."
  Track estimate against actual. The kit learns to quote like a contractor.
- Mistakes that file themselves. Every rejected review and failure gets
  distilled to one line in a bucket. New tasks that match carry the warning:
  "tasks like this usually fail on X, check it first."
- The kit reads its own month. Once a wave, a cheap model reads every redo
  and failure and proposes "what we keep getting wrong" as pattern entries.
  The human approves each with one glance.

When an idea here becomes real work, it gets its own section below this
line (or its own file) with the design, the tasks, and the before and after
numbers. The WHY above travels into every task description.
