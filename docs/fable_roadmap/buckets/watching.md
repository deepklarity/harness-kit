# Watching

**Why.** Right now the answer to "what happened last night?" is grep. Great
watching does two jobs at once: it makes steering easy, and it makes the
whole thing enjoyable. Seeing your agents work should feel like watching a
race, not reading a server log.

**Ideas.**
- Mission control. A live view where every agent has a card: what it's
  doing, how long, what it just said. The state of the world in one glance.
- Replay. Scrub any finished task like a video. Here's where it read the
  code, here's where it went wrong, here's the fix landing.
- The wave story. One scrollable page per wave: what shipped with proof,
  what failed and why, what it cost. Doubles as the draft of the feature
  doc, because it already contains what changed and why.
- Diagrams on demand. Any spec or flow rendered as a picture when a picture
  answers faster than text.

When an idea here becomes real work, it gets its own section below this
line (or its own file) with the design, the tasks, and the before and after
numbers. The WHY above travels into every task description.
