The merge agent can merge two versions of a file wrong, without asking anyone task 344 · Trust

When two versions of the same file conflict, it is allowed to merge them on its own. Three times in one night it merged them wrong — the result looked fine, ran fine, but lost or mixed up changes, and a person had to untangle it in git each time. The check we added catches code that won't run. It can't catch a merge that runs but is wrong.

PlanChange the rule: merge only when the result is provably right, otherwise stop and ask a person — and act on their written answer. First item on the next-five list.
