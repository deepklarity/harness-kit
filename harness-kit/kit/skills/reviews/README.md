# reviews

Reviewing changes. Each skill's tier is a row in [`../skills.csv`](../skills.csv); the full list of categories is [`../README.md`](../README.md).

| Skill | What it does |
|---|---|
| [hk-pr-review](hk-pr-review/SKILL.md) | Review a pull request, a branch, or the diff since a ref as one HTML page: a readiness score out of 5, findings in blockers, major and minor, a Standards section and a Spec section. |
| [pr-task-summary](pr-task-summary/SKILL.md) | Turn a pasted list of people, tasks, PR links and statuses into one HTML page grouped by person, with a Status and an Action line per task. |
