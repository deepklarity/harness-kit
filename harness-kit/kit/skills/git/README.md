# git

Merging, conflicts, changelogs. Each skill's tier is a row in [`../skills.csv`](../skills.csv); the full list of categories is [`../README.md`](../README.md).

| Skill | What it does |
|---|---|
| [hk-changelog](hk-changelog/SKILL.md) | Write a CHANGELOG.md entry from the branch's diff against main, then commit it on a changelog branch and open a PR. |
| [hk-merge-pr](hk-merge-pr/SKILL.md) | Squash-merge a GitHub PR with a commit message written from its commits and the repo's attribution trailer. |
| [hk-merge-resolve](hk-merge-resolve/SKILL.md) | Resolve the conflicts of an in-progress merge, rebase or cherry-pick, then run the affected suite with scripts/verify.sh. |
