# knowledge

Capturing, writing up and handing over knowledge. Each skill's tier is a row in [`../skills.csv`](../skills.csv); the full list of categories is [`../README.md`](../README.md).

| Skill | What it does |
|---|---|
| [cross-repo-skill-comparison](cross-repo-skill-comparison/SKILL.md) | Compare the Claude skills across two or more repos (paths or GitHub links) and write one HTML page: which skills exist where, which copy is newest, what each fork changed, which are worth pulling into this repo. |
| [handoff](handoff/SKILL.md) | Compact the current conversation into a handoff document a fresh agent can resume from: where the work stands, what was decided and why, what is next, which files to open first. |
| [hk-pdf-export](hk-pdf-export/SKILL.md) | Turn an HTML page, or content that has to become one first, into a PDF in the house design and check nothing was lost. |
| [hk-skill-creator](hk-skill-creator/SKILL.md) | Create a skill in this repo's layout (the body under docs/skills plus the .claude/skills stub) or run evals on one: draft it, run it against a baseline on realistic prompts, judge the outputs, tighten the description. |
| [hk-writeup](hk-writeup/SKILL.md) | Put what the user asked for, and nothing else, onto one self-contained HTML page in the house voice. |
| [matt-writing-for-agents](matt-writing-for-agents/SKILL.md) | Reference for how a document an agent reads is written: context pointers, the information ladder, completion criteria, leading words, no-ops. |
